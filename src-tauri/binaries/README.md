# FFmpeg Binaries Folder

Place `ffmpeg.exe` here for bundling with the app.

## Download FFmpeg
Get the static build from: https://www.gyan.dev/ffmpeg/builds/

1. Download "ffmpeg-release-essentials.zip"
2. Extract `bin/ffmpeg.exe` to this folder
3. Rebuild the app

For development, FFmpeg in PATH is used automatically.
